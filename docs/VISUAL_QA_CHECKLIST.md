# Visual QA Checklist

Use this checklist before launch and after any visual change.

## Global visual identity

- [ ] The visual identity feels premium, dark, executive and technology-oriented.
- [ ] The site uses Ricardo Zulkiewicz consistently as the public name.
- [ ] Typography feels clean and readable on desktop and mobile.
- [ ] Section spacing feels intentional and not cramped.
- [ ] Buttons have enough contrast and clear hover states.
- [ ] Cards do not overlap text or other elements.
- [ ] No text overflows outside cards or page boundaries.
- [ ] Decorative marks do not block content.

## Desktop review

- [ ] `/`
- [ ] `/pt`
- [ ] `/cv`
- [ ] `/cv/access` with valid token when available
- [ ] `/privacidade`
- [ ] `/termos`
- [ ] 404 page
- [ ] Error page when testable
- [ ] Loading state when testable

## Mobile review

- [ ] Header and menu work correctly.
- [ ] CTA buttons are easy to tap.
- [ ] Hero title does not break awkwardly.
- [ ] Forms are easy to complete.
- [ ] Footer links wrap cleanly.
- [ ] No horizontal scrolling.

## CV request page

- [ ] Required fields are clear.
- [ ] Consent text is visible and understandable.
- [ ] Validation errors are readable.
- [ ] Success state is clear.
- [ ] The page explains that the CV is not a public direct download.
- [ ] The page feels intentional rather than restrictive for no reason.

## Legal and trust pages

- [ ] Privacy page is accessible.
- [ ] Terms page is accessible.
- [ ] Security contact file is available.
- [ ] Humans file is available.

## SEO and preview

- [ ] Browser title is correct.
- [ ] Description is correct.
- [ ] LinkedIn preview looks professional.
- [ ] WhatsApp preview looks professional.
- [ ] Sitemap is available.
- [ ] Robots file excludes non-public routes.

## Final launch confidence

- [ ] No temporary text remains visible.
- [ ] No placeholder values are visible to visitors.
- [ ] No direct file link is visible for the CV.
- [ ] The site feels like a finished professional product.
